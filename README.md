# First Basic Working DApp Scaffold

A simple Next.js App Router project — my first decentralized app scaffold.  
This repo demonstrates a clean setup with `app/layout.js` and `app/page.js`.

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/anand-lab25/first-dapp.git
cd first-dapp

#### Install dependencies
npm install

##### Run the development server
npm run dev
Open http://localhost:3000 (localhost in Bing) in your browser to see the app.

🛠️ Scripts

npm run dev → Start development server

npm run build → Build production bundle

npm start → Run production server

✅ Notes
Built with Next.js App Router.

Requires Node.js 18+ and npm 9+.

Clean scaffold — ready for DApp integration.
